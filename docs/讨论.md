# 写博客功能改进讨论

## 问题描述

当前写博客部分（admin.html 中的写文章界面）存在以下问题：
- 界面元素太多：标题、摘要、标签、封面图、图片管理等一堆表单干扰写作
- 不适合沉浸式写作体验

## 用户需求

| 需求 | 描述 |
|------|------|
| 极简模式 | 进入写作页只看到标题+编辑器，其他设置折叠或延后填写 |
| 延后设置 | 摘要、封面图、标签等发布时再填，不要一开始就显示 |
| 沉浸式编辑 | 像 Notion/Typora 那样，标题和正文一体化，没有分离的表单 |
| 轻量编辑器 | 替换 Toast UI Editor，使用更轻量的编辑器 |

## 讨论记录

### 2026-09-04 第一次讨论

**编辑器选择：**

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| Milkdown v6 | 所见即所得，Notion 体验 | 需要打包工具，纯静态 HTML 无法直接使用 | ❌ 放弃 |
| Vditor | CDN 友好，支持所见即所得/即时渲染/分屏预览，国人开发 | 非 Milkdown | ✅ 选择 |
| 保留 Toast UI | 已有集成 | 太重，界面复杂 | ❌ 放弃 |

**最终选择：Vditor**
- 支持三种模式：所见即所得、即时渲染（类似 Typora）、分屏预览
- CDN 友好，有 UMD 构建，无需打包工具
- MIT 协议
- 支持 Markdown 扩展语法（思维导图、流程图等）
- 内置代码高亮
- 支持图片上传

**发布流程：**

| 方案 | 描述 | 结论 |
|------|------|------|
| 发布时弹窗填写 | 点发布按钮后弹出弹窗填写标签、封面等 | ✅ 选择 |
| 侧边栏折叠 | 侧边栏收起，点展开后填写元数据 | ❌ |
| 草稿→发布两步 | 先保存草稿，发布时才填写完整信息 | ❌ |

**页面结构：**
- 改造现有 admin.html 中的写文章部分（而非独立页面）

## 实施方案

### 目标

将写文章界面改造为极简沉浸式写作体验：

**改造前：**
```
┌────────────────────────────────────────┐
│ 标题输入框                              │
│ 摘要输入框 | 标签选择器 | 状态选择      │
│ 封面图预览 | 上传/选择封面 | 文中图片列表 │
│ 图库按钮 | 上传图片按钮                 │
│ ┌────────────────────────────────────┐ │
│ │ Toast UI Editor（工具栏+编辑区）    │ │
│ └────────────────────────────────────┘ │
│ 字数统计 | 清空按钮 | 保存按钮          │
└────────────────────────────────────────┘
```

**改造后：**
```
┌────────────────────────────────────────┐
│ [← 返回]            [导出MD] [发布 ▾]  │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 输入文章标题...                     │ │
│ ├────────────────────────────────────┤ │
│ │                                    │ │
│ │ Vditor 编辑器（沉浸式写作）         │ │
│ │                                    │ │
│ │                                    │ │

└────────────────────────────────────────┘

点击 [发布 ▾] 后弹出弹窗：
┌──────────────────────────┐

│                          │
│    [取消]  [确认发布]     │
└──────────────────────────┘
```

### 技术实现

#### 1. 引入 Vditor

CDN 引入：
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/vditor@3.10/dist/index.min.css">
<script src="https://cdn.jsdelivr.net/npm/vditor@3.10/dist/index.min.js"></script>
```

#### 2. 移除 Toast UI 相关文件

删除以下 vendor 文件引用：
- `js/vendor/toastui-editor.min.css`
- `js/vendor/toastui-editor-dark.min.css`
- `js/vendor/toastui-editor.bundle.min.js`
- `js/vendor/toastui-i18n-zh-cn.js`

#### 3. 简化写文章 HTML 结构

移除：
- 摘要输入框（移到发布弹窗）
- 标签选择器（移到发布弹窗）
- 状态选择（移到发布弹窗）
- 封面图管理区域（移到发布弹窗）
- 文中图片列表（移到发布弹窗）
- 图库/上传图片按钮（编辑器内支持拖拽上传）

保留：
- 标题输入框（顶部，大字体）
- Vditor 编辑器（占满剩余空间）
- 字数统计（底部）
- 返回按钮、导出MD按钮、发布按钮（顶部工具栏）

#### 4. 新增发布弹窗

弹窗内容：
- 状态选择（发布/草稿）
- 标签选择器（复用现有标签选择逻辑）
- 摘要输入（可选，不填自动提取正文前150字）
- 封面图管理（上传/从图库选择/移除）

#### 5. Vditor 初始化配置

```javascript
const vditor = new Vditor('vditor', {
  height: 'calc(100vh - 180px)',  // 自适应高度
  mode: 'wysiwyg',  // 默认所见即所得模式
  theme: 'dark',
  toolbar: [
    'emoji', 'headings', 'bold', 'italic', 'strike', 'link',
    '|', 'list', 'ordered-list', 'check', 'outdent', 'indent',
    '|', 'quote', 'line', 'code', 'inline-code', 'table',
    '|', 'upload', 'record',
    '|', 'edit-mode', 'fullscreen',
    '|', 'undo', 'redo',
    '|', 'more'
  ],
  upload: {
    url: '/api/admin?action=upload',  // 图片上传接口
    fieldName: 'file',
    format: (files, responseText) => {
      // 处理上传响应
    }
  },
  cache: {
    enable: true,  // 启用本地缓存，防止内容丢失
  },
  after: () => {
    vditor.setValue('');  // 初始化
  }
});
```
