# 个人博客系统 - 操作文档

## 快速开始

### 1. 本地运行

#### 方法一：使用本地服务器（推荐）

**使用Node.js：**

```bash
# 安装http-server
npm install -g http-server

# 在项目目录运行
http-server -p 8080

# 打开浏览器访问
# http://localhost:8080
```

**使用Python：**

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

**使用VS Code：**

1. 安装Live Server插件
2. 右键点击 `index.html`
3. 选择 "Open with Live Server"

#### 方法二：直接打开

1. 下载或克隆项目到本地
2. 双击打开 `index.html` 文件
3. 即可在浏览器中查看博客

> ⚠️ 注意：直接打开文件可能无法加载Markdown文件，建议使用方法一。

### 2. 部署到GitHub Pages

#### 步骤一：创建GitHub仓库

1. 登录GitHub
2. 点击右上角 "+" -> "New repository"
3. 填写仓库名称，如：`my-blog`
4. 选择 Public
5. 点击 "Create repository"

#### 步骤二：上传文件

**方法一：使用Git命令**

```bash
# 克隆仓库
git clone https://github.com/你的用户名/my-blog.git
cd my-blog

# 复制项目文件到仓库目录
# ...

# 添加.nojekyll文件（重要！）
touch .nojekyll

# 提交并推送
git add .
git commit -m "Initial commit"
git push origin main
```

**方法二：使用GitHub网页**

1. 进入仓库页面
2. 点击 "Add file" -> "Upload files"
3. 拖拽所有项目文件
4. 确保包含 `.nojekyll` 文件
5. 点击 "Commit changes"

**方法三：使用GitHub Desktop**

1. 下载并安装 [GitHub Desktop](https://desktop.github.com/)
2. 登录GitHub账号
3. 克隆仓库到本地
4. 复制项目文件到仓库目录
5. 点击 "Commit to main"
6. 点击 "Push origin"

#### 步骤三：启用GitHub Pages

1. 进入仓库设置：点击 "Settings"
2. 左侧菜单找到 "Pages"
3. Source 选择 "Deploy from a branch"
4. Branch 选择 "main" 和 "/ (root)"
5. 点击 "Save"

#### 步骤四：等待部署完成

1. 进入仓库的 "Actions" 选项卡
2. 查看部署工作流状态
3. 等待5-10分钟让部署完成

部署完成后，你的博客将可以通过以下地址访问：
```
https://你的用户名.github.io/my-blog/
```

> ⚠️ 重要：确保项目根目录包含 `.nojekyll` 文件，否则GitHub Pages可能无法正确处理某些文件。

## 添加文章

### 1. 创建Markdown文件

在 `posts` 文件夹中创建新的 `.md` 文件，例如：`my-new-post.md`

### 2. 编写Frontmatter

文件开头必须包含Frontmatter信息：

```yaml
---
title: 我的新文章
date: 2026-07-21
tags: [技术, 生活]
author: 你的名字
excerpt: 这是文章的摘要，会显示在卡片上。
image: images/cover.jpg  # 可选，封面图片路径
---

正文内容...
```

#### Frontmatter字段说明

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| title | 是 | 文章标题 | `我的第一篇文章` |
| date | 是 | 发布日期 | `2026-07-21` |
| tags | 是 | 标签数组 | `[技术, JavaScript]` |
| author | 否 | 作者名 | `渡鸦NULL` |
| excerpt | 否 | 文章摘要 | `这是摘要...` |
| image | 否 | 封面图片路径 | `images/cover.jpg` |

### 3. 编写正文

使用标准Markdown语法编写文章内容：

```markdown
# 一级标题

## 二级标题

正文内容...

- 列表项1
- 列表项2

**粗体** 和 *斜体*

[链接文字](https://example.com)

![图片描述](images/image.jpg)

```javascript
console.log('Hello World!');
```
```

### 4. 更新manifest.json

打开 `posts/manifest.json` 文件，添加新文章的文件名：

```json
[
    "blog-usage-guide.md",
    "github-guide.md",
    "javascript-async.md",
    "my-new-post.md"
]
```

### 5. 刷新页面

刷新博客页面，新文章将自动显示。

## 使用图片

### 添加图片

1. 将图片放入 `images/` 文件夹
2. 在Markdown中引用：

```markdown
![图片说明文字](images/your-image.jpg)
```

### 图片功能

- **说明文字**：图片说明文字（alt文本）会自动显示在图片下方作为说明
- **灯箱功能**：点击图片可打开灯箱放大查看
- **缩放拖拽**：灯箱内支持鼠标滚轮缩放和拖拽
- **懒加载**：图片支持懒加载，提高页面加载速度

### 图片路径

支持两种路径格式：

```markdown
# 相对路径（推荐）
![图片](images/cover.jpg)

# 绝对URL
![图片](https://example.com/image.jpg)
```

            '--bg-primary': '#your-bg-color',
            '--bg-secondary': '#your-secondary-bg',
            '--bg-tertiary': '#your-tertiary-bg',
            '--bg-card': '#your-card-bg',
            '--text-primary': '#your-text-color',
            '--text-secondary': '#your-secondary-text',
            '--text-muted': '#your-muted-text',
            '--accent': '#your-accent-color',
            '--accent-dim': '#your-dim-accent',
            '--border': '#your-border-color',
            '--border-light': '#your-light-border',
            '--shadow': 'rgba(r, g, b, alpha)',
            '--glow': 'rgba(r, g, b, alpha)'
        }
    }
}
```

3. 保存文件，刷新页面即可使用新主题

## AI智能助手

### 配置

打开 `js/chat.js`，替换 API Key：

```javascript
config: {
    apiUrl: 'https://open.bigmodel.cn/api/paas/v4/chat/completions',
    apiKey: 'YOUR_API_KEY_HERE',  // 替换为你的智谱 API Key
    model: 'glm-4-flash',
    maxTokens: 1024
}
```

API Key 获取地址：https://open.bigmodel.cn/

### 使用方法

1. 点击右下角聊天图标打开对话窗口
2. 在底部输入框输入问题
3. 按回车或点击发送按钮
4. 等待AI回复

### 功能特性

- **拖拽移动**：拖拽窗口标题栏可移动窗口位置
- **调整大小**：拖拽左上角手柄可调整窗口大小
- **历史保存**：对话历史自动保存，刷新页面不丢失
- **清空对话**：点击清空按钮可清空对话历史
- **关闭窗口**：点击关闭按钮可关闭对话窗口

### 切换AI模型

在 `js/chat.js` 中修改 `model` 字段：

```javascript
config: {
    model: 'glm-4-flash',   // 快速模型（默认）
    // model: 'glm-4',      // 标准模型
    // model: 'glm-4v',     // 多模态模型（支持图片）
}
```

## 常见问题

### Q: 文章不显示？

**检查清单：**

1. ✅ 文件是否在 `posts` 文件夹中
2. ✅ 文件扩展名是否为 `.md`
3. ✅ 文件名是否添加到 `manifest.json`
4. ✅ Frontmatter格式是否正确
5. ✅ 是否刷新了页面

### Q: 标签不显示？

**检查清单：**

1. ✅ tags字段是否使用数组格式 `[标签1, 标签2]`
2. ✅ 标签名称是否正确
3. ✅ 是否刷新了页面

### Q: 主题切换无效？

**检查清单：**

1. ✅ 浏览器是否支持CSS变量
2. ✅ 是否禁用了JavaScript
3. ✅ 清除浏览器缓存后重试

### Q: 代码不高亮？

**检查清单：**

1. ✅ 代码块是否使用正确的语法
2. ✅ 是否指定了语言名称
3. ✅ 检查浏览器控制台是否有错误

### Q: 部署后样式丢失？

**检查清单：**

1. ✅ 文件路径是否正确
2. ✅ 是否使用了相对路径
3. ✅ GitHub Pages是否部署完成
4. ✅ 是否添加了 `.nojekyll` 文件

### Q: Markdown文件返回404？

**解决方案：**

1. 确保项目根目录包含 `.nojekyll` 文件
2. 检查GitHub Pages设置是否正确
3. 等待5-10分钟让部署完成
4. 清除浏览器缓存后重试

### Q: AI助手无法使用？

**检查清单：**

1. ✅ 是否配置了正确的API Key
2. ✅ 网络连接是否正常
3. ✅ 检查浏览器控制台是否有错误
4. ✅ API Key是否过期

### Q: 图片灯箱不工作？

**检查清单：**

1. ✅ 图片是否正确加载
2. ✅ 是否禁用了JavaScript
3. ✅ 检查浏览器控制台是否有错误

## 高级用法

### 1. 使用GitHub Actions自动部署

创建 `.github/workflows/deploy.yml` 文件：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      
      - name: Setup Pages
        uses: actions/configure-pages@v4
      
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### 2. 使用自定义域名

1. 在项目根目录创建 `CNAME` 文件
2. 文件内容为你的域名，如：`blog.example.com`
3. 在域名服务商处配置CNAME记录指向 `你的用户名.github.io`

### 3. 批量添加文章

3. 提交并推送到GitHub
