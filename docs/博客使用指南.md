# 博客使用指南

> 适用于 v3.24.x（后台地址 `/admin`，文章存储于 Netlify Blobs）。本文从零开始，覆盖前台浏览、AI 能力、后台管理与发布全流程。

---

## 一、前台页面

打开博客首页，顶栏与内容区：

### 1.1 顶栏

- **品牌**：左上角站点名称（可在「后台 → 博客设置 → 站点名称」修改）
- **视图切换**：`文章 / 图库 / 每日新闻 / 我的` 四个视图按钮（可在设置中选择显示哪些视图）

### 1.2 文章视图

- 瀑布流卡片，图片懒加载，卡片含封面、作者头像、标题、标签、摘要、日期与预计阅读时长
- 顶部「全部 / 标签」快捷筛选 + 搜索框，点击标签面板可查看全部标签及文章数

### 1.3 图库视图

- 图片通过「后台 → 图片管理」上传，自动转 WebP，可打分类标签
- 图库支持按标签筛选；点击图片打开灯箱：左右切换、下载、幻灯片播放、页码

### 1.4 每日新闻

- 列表式聚合资讯，按出品方筛选，点击可站内阅读或打开原文，数据自动更新

### 1.5 我的视图（仪表盘）

- 欢迎区（头像、昵称、签名、时钟）、统计（文章/标签/字数/图库）、最近文章、热门标签、快捷入口、关于信息

---

## 二、文章阅读体验

点击文章卡片进入阅读页：

- **左侧目录**：默认展开、可折叠、可搜索，滚动时自动高亮当前章节
- **阅读工具栏**（正文上方）：字号 `A−/A+`、行距、衬线/无衬线、护眼、夜间、专注模式，均自动记忆
- **顶部进度条**：实时显示阅读进度
- **快捷键**：`J/K` 上下篇、`T/B` 顶部/底部、`/` 聚焦目录搜索、`Q` 切主题、`E` 开关 AI 对话
- **文末**：上一篇/下一篇卡片、留言区

---

## 三、留言区

文章底部与「我的」视图均有留言功能：

- 填写昵称 + 内容提交，支持上传 1 张图片（jpg/png/gif/webp，≤2MB）
- 留言存储于 Netlify Blobs（`/api/comments`），后台「评论管理」可查看/删除
- 每条留言的 `@昵称` 会高亮，点击「回复」自动填入 `@昵称 `

---

## 四、AI 助手（聊天）

文章页右下角悬浮球打开 AI 对话窗口（首页右下角按钮同样可开）：

### 4.1 对话

- 流式输出（打字机效果）、Markdown 渲染、代码高亮，可随时「停止」
- 每条回复下有「复制 / 重新生成」
- **文章页直接提问**：打开对话后直接问「这篇文章主要讲了什么？」，AI 会自动结合当前文章内容回答，**无需任何前缀**
- **划词问答**：选中正文文字弹出「解释 / 翻译 / 润色」，一键调用 AI
- **快捷指令**：输入 `/` 唤起菜单（解释 / 翻译 / 润色 / 总结 / 写代码）
- 字数统计、窗口可拖拽/缩放并记忆位置、未读角标

### 4.2 会话管理

- 点聊天窗口右上角漏斗图标打开会话面板：新建 / 切换 / 删除
- 会话以首条消息自动命名，历史自动保存到 Netlify Blobs，刷新/换设备不丢

### 4.3 AI Agent：对话里生成文章

在 AI 对话窗口直接输入指令即可让 AI 自动写文章并发布：

```
@管理员 写一篇 3000 字的 Python 入门教程并发布
```

- 会弹出输入框要求**后台登录密钥**（密钥正确才会生成）
- 提交后对话中显示**实时进度条**（排队 → 撰写 → 提取摘要 → 保存发布 → 完成）
- 完成后给出文章链接，可直接点开查看
- 生成的文章**自动从图库随机挑一张图作为封面**（图库为空则无封面）

### 4.4 配置（模型库选择）

后台「博客设置 → AI 设置」中配置：

- **AI 助手**：前台聊天用。选「厂商 → 模型 → 粘贴 API Key」三步即可，无需手填接口地址与模型名；点「测试连接」可验证
- **写作 AI**：后台写文章 / AI Agent 生成用，独立配置；未填时自动复用 AI 助手
- 内置模型库覆盖：智谱 GLM、DeepSeek、OpenAI、Kimi、通义千问 + 自定义

## 六、后台管理

后台地址 `/admin`，输入密钥登录（默认 `1111`，可在设置中修改）。

### 6.1 文章管理

- 列表按「已发布 / 草稿」分组，支持标题/标签实时搜索，可拖拽排序
- 支持一键发布 / 下架、删除、导入 `.md`、导出 `.md`

### 6.2 写文章（所见即所得编辑器）

- 打开「写文章」，编辑器为**所见即所得**（类似 Obsidian）：选中文字点工具栏按钮即可排版，无需手写 Markdown 语法
- 支持 H2/H3、加粗、斜体、删除线、引用、列表、链接、表格、图片、代码块等
- 可切换「所见即所得 ⇄ Markdown 源码」；文章始终以 Markdown 存储
- 拖拽 / 粘贴图片自动上传，封面可从图库选
- **🤖 AI 写作**：侧栏 AI 写作助手，输入要求生成全文/大纲/标题/续写/润色/摘要+标签
- **🤖 AI Agent**：命令面板，输入指令直接生成文章（进度实时显示）

### 6.3 评论管理

- 全站留言汇总，按文章展示，可删除

### 6.4 图片管理

- 上传自动转 WebP（限 10MB），分「未分类」与分类标签，支持拖拽移动、批量删除
- 图片标签可在「标签管理」维护

### 6.5 标签管理

- 文章标签（来自文章）与图片标签（来自图片分类），支持添加、重命名、删除

### 6.6 博客设置（分三类）

- **前台设置**：站点名称与标题、网站图标 favicon、顶部品牌、个人资料（头像/用户名/签名）、导航页面开关、仪表盘统计项、导航标签、关于信息
- **AI 设置**：AI 助手、写作 AI、AI Agent（触发词 / 发布策略 / 提示词分离）
- **后台设置**：后台密码
- 设置卡片可**拖动排序**（服务端保存，刷新不丢）、可折叠

### 6.7 AI Agent 设置（AI 设置 → AI Agent）

| 项 | 说明 |
|----|------|
| 启用开关 | 关闭后对话里 @管理员 不生效 |
| 生成文章触发词 | 默认 `@管理员,@博主`（对话中触发生成，需后台密钥） |
| 评论触发生成后 | 存草稿（默认，审核后发布）或直接发布 |
| 指令长度上限 | 单条指令最大字数 |
| 提示词 | 默认与「写作 AI」一致；可关闭共用后单独设置 |

## 七、发布文章流程

1. 打开 `/admin`，输入密钥登录
2. 进入「写文章」，填写标题、摘要、标签、状态（发布/草稿）
3. 选封面（或留空，保存时自动从图库随机选一张）
4. 在所见即所得编辑器里写正文，点「💾 保存文章」
5. 已发布文章会置顶显示在首页；首页有 60 秒缓存，等一会儿或强制刷新即可看到

> 也可以直接导入 `.md` 文件（支持 Frontmatter：`title / date / tags / excerpt / image`）。

## 九、常见问题

### Q: 发布了文章首页不显示？

1. 确认状态是「已发布」（草稿不显示）
2. 首页有 60 秒缓存，等待或强制刷新 `Ctrl+F5`

### Q: 改完设置前台没生效？

设置存于 Blobs，刷新前台即可；仍未生效则强制刷新。

### Q: @管理员 生成文章没反应？

1. 确认「AI Agent」已启用
2. 确认输入的**后台密钥正确**
3. 确认「写作 AI / AI 助手」已配置模型与 API Key

### Q: 生成文章很慢？

长文生成是模型逐字生成 + 分段续写，属正常现象；换更快的小模型（如 GLM-4-Flash）可明显提速。

### Q: 忘了后台密码？

默认 `1111`；若改过，需在部署环境 `ADMIN_KEY` 环境变量或 Blobs `blog-auth` 中找回/重置。
