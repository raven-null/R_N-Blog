## 三、给 AI 的三句话

如果你是被派来写文章的 AI，只需记住：

1. **先读 [05-AI-写文章指南](./05-AI-写文章指南.md)**，再读 [04-写作规范](./04-写作规范.md)；
2. 输出必须是**能直接粘进后台的完整文章**：标题、摘要、标签、正文缺一不可；
3. 不确定的事实不要编，宁可留一句「待作者核实」。
