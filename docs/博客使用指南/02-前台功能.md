# 02 · 前台功能

## 一、首页：四个视图

顶栏可切换，显示哪些视图由后台「博客设置 → 前台设置 → 导航页面开关」控制。

### 文章

- 瀑布流卡片：封面、标题、标签、摘要、日期、预计阅读时长
- 顶部可按「全部 / 标签」筛选，右侧有搜索框与标签面板（含每个标签的文章数）
- 筛选状态会写进 URL（如 `?tag=技术`），可以分享

### 图库

- 图片在后台「图片管理」上传，自动转 WebP，可打分类
- 支持按分类筛选；点开是灯箱：左右切换、下载、幻灯片、页码
- `R16 / R18` 分类只有拿到图库密码的管理员身份才看得到

### 每日新闻

- 列表式资讯聚合，按出品方筛选
- 点条目：有站内正文就站内读，没有就新窗口打开原文

### 我的

- 欢迎区（头像、昵称、签名、时钟）
- 统计（文章 / 标签 / 字数 / 图库）
- 最近文章、热门标签、快捷入口、关于
- 底部留言区（和文章底部是同一套留言）

## 二、阅读页

- **左侧目录**：默认展开、可折叠、可搜索，滚动时自动高亮当前章节
- **顶部进度条**：显示阅读位置
- **阅读工具栏**（正文上方）：
  - `A− / A+` 字号（13–22px）
  - 行距 1.6 / 1.8 / 2.0 循环
  - 衬线 ⇄ 无衬线
  - 护眼、夜间、专注模式（`ESC` 退出专注）
  - 以上选择都会记在本地，下次自动恢复
- **文末**：上一篇 / 下一篇、留言区
- **长文章**会自动分章，阅读端按需加载章节

### 快捷键

| 键 | 作用 |
|----|------|
| `J` / `K` | 下一篇 / 上一篇 |
| `T` / `B` | 回到顶部 / 到底部 |
| `W` / `S` | 上下滚动一屏 |
| `A` / `D` | 浏览器后退 / 前进 |
| `/` | 聚焦目录搜索 |
| `Q` | 切换主题 |
| `E` | 开 / 关 AI 对话 |
| `ESC` | 退出专注模式、关闭灯箱 |

## 三、AI 对话

入口：文章页右下角悬浮球，或首页/mobile 悬浮菜单。**快捷键 `E`**（文章页）。

### 能做什么

- 流式输出（打字机效果），可随时「停止」
- 支持 Markdown 与代码高亮，回复可「复制 / 重新生成」
- **文章页直接提问**：打开就自动带上当前文章，直接问「这篇文章主要讲了什么」即可，不需要前缀
- 需要显式点名助手时，用 `@ai` 或 `@助手` 开头，发送前会被剥掉
- **划词问答**：选中正文文字弹出「解释 / 翻译 / 润色」
- **斜杠指令**：输入 `/` 唤起（解释 / 翻译 / 润色 / 总结 / 写代码）
- 输入框有字数统计，上限 2000

### 会话

- 右上角漏斗图标打开会话面板：新建 / 切换 / 删除
- 会话按首条消息自动命名，存到 Netlify Blobs（`/api/chat`），换设备也能接着聊

### 人设

- 访客端助手的身份是「博客管理员」，提示词在 `public/js/chat.js` 的 `systemPrompt`
- **表达规范：不用 Emoji**，需要语气时最多一个颜文字，正式技术内容不用

> 这个助手只负责聊天答疑。**它不会替你写文章**。
> 站内的「写作助手」（后台写作页侧栏）也**只回答写作问题、不写正文、不读正文**——这是刻意的设计。
> 要 AI 写文章，走 [05-AI-写文章指南](./05-AI-写文章指南.md) 的流程。

## 四、主题

点主题按钮循环切换 10 套：Dark / Light / Cyberpunk / Sepia / Neon / Nord / Dracula / Ocean / Forest / Sunset。
选择存在本地，下次访问自动恢复。

---

## 五、留言

- 昵称 + 内容，可带 1 张图片（jpg/png/gif/webp，≤2MB）
- `@昵称` 会高亮，点「回复」自动填入 `@昵称 `
- 留言可在后台「评论管理」查看和删除

## 六、移动端

- 宽屏 ≤773px 时目录栏隐藏，改用右下角悬浮球菜单（目录 / 返回 / 首页 / 主题 / AI）
- 文章列表自动从多列收敛为单列
- 灯箱支持触摸缩放与拖拽
