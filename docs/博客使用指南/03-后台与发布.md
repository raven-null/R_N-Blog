# 03 · 后台与发布

> 后台地址 `/admin`，默认密钥 `1111`（环境变量 `ADMIN_KEY` 优先）。
> 写作规范见 [04-写作规范](./04-写作规范.md)，AI 写文章见 [05-AI-写文章指南](./05-AI-写文章指南.md)。

---

## 一、后台能干什么

| 模块 | 作用 |
|------|------|
| 文章 | 列表、搜索、拖拽排序、发布 / 下架、删除、导入导出 `.md` |
| 写文章 | 所见即所得编辑器 + 侧栏 AI（答疑用） |
| 评论 | 全站留言汇总，可删除 |
| 图片 | 上传转 WebP、分类标签、拖拽移动、批量删除 |
| 标签 | 文章标签与图片标签的增删改 |
| 文档 | 文档类内容管理 |
| 博客设置 | 前台设置 / AI 设置 / 后台设置 |

文章、图片、文档、设置全部存 **Netlify Blobs**，保存即生效，不触发部署。

## 二、写文章页

### 编辑器

- **所见即所得**：选中文字点工具栏按钮排版，不用记 Markdown 语法
- 可切换「所见即所得 ⇄ Markdown 源码」，文章始终以 Markdown 存储
- 支持 H2/H3、加粗、斜体、删除线、引用、列表、链接、表格、图片、代码块
- 拖拽或粘贴图片会自动上传
- 侧栏有**大纲**（正文结构导航）

### 顶部字段

| 字段 | 说明 |
|------|------|
| 标题 | 必填，卡片与阅读页的主标题 |
| 摘要 | 显示在卡片上；不填则从正文截取 |
| 标签 | 决定筛选项与「热门标签」 |
| 状态 | 已发布 / 草稿，**草稿不在前台显示** |
| 封面 | 可从图库选；留空时保存会从图库随机挑一张 |
| 作者 | 决定卡片头像 |

### 侧栏 AI

侧栏「AI」页签是**写作问答助手**，刻意只做一件事：回答你在写作中问的问题。
它**不写入正文、不读正文、不保存历史**——密钥也不下发到浏览器，由 `functions/admin.ts` 的服务端代调。

适合问：近义词、标点断句、段落结构、标题摘要怎么写、Markdown 语法、概念表述。

### 长文章

正文字符数超过 **30000** 时自动分章存储，阅读端按需加载章节。

## 三、导入 / 导出 Markdown

### 导出

文章可导出为 `.md`，正文即文章内容。

### 导入

导入时**只解析这四个 frontmatter 字段**：

```yaml
---
title: 文章标题
tags: [技术, 实践]
excerpt: 一句话摘要
image: 封面地址
---
```

- `date`、`update`、`author` 等字段**导入时会被忽略**，要在后台表单里另行设置
- 文件名去掉 `.md` 会作为标题兜底
- 正文过大时浏览器暂存会失败，会提示「导入内容过大」

## 四、图片

- 上传自动转 WebP，单张上限 10MB
- 分「未分类」与各分类标签，可拖拽移动、批量删除
- 图片标签在「标签管理」维护
- 文章封面、正文配图都可以从图库挑

## 五、博客设置

分三类，卡片可拖动排序、可折叠，保存在服务端。

### 前台设置

站点名称与标题、favicon、顶部品牌、个人资料（头像/昵称/签名）、导航页面开关、仪表盘统计项、导航标签、关于信息。

### AI 设置

| 项 | 说明 |
|----|------|
| AI 助手 | 前台访客聊天用。选「厂商 → 模型 → 贴 API Key」三步，可测试连接 |
| 写作 AI | 后台写作页侧栏用，独立配置；未填时复用 AI 助手 |
| 系统提示词 | 留空则用代码里的默认人设 |

内置模型库覆盖智谱 GLM、DeepSeek、OpenAI、Kimi、通义千问，也可自定义接口地址与模型名。

> 密钥只在服务端使用：前台 `/api/ai`、写作页 `action=ai-write` 都由后端代调，浏览器拿不到 Key。

### 后台设置

后台密码。改完记住，密钥一旦丢失只能从环境变量 `ADMIN_KEY` 或 Blobs `blog-auth` 重置。
