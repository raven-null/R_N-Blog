# 08 · 常见问题

> 按症状查。找不到答案时，先按 F12 看控制台报错，再对照 [03-后台与发布](./03-后台与发布.md) 的对应模块。

---

## 一、发布与显示

### Q：文章保存了，首页没有

1. 状态是不是「已发布」——**草稿不在前台显示**
2. 首页有 **60 秒缓存**，等一会儿，或 `Ctrl+F5` 强制刷新
3. 换标签筛选看看，可能只是被筛掉了

### Q：改了文章，前台还是旧内容

文章页通常不走缓存，首页列表走 60 秒缓存。等一会儿或强制刷新。

### Q：改了后台设置，前台没反应

设置存在 Netlify Blobs，刷新前台即可生效；不生效就强制刷新浏览器。

### Q：删除的文章还能点开

历史链接可能命中浏览器缓存，强制刷新一次；确实还在说明删除请求失败，看控制台。

---

## 二、导入导出

### Q：导入 `.md` 后日期、作者没了

**这是预期行为**。导入只解析 `title / tags / excerpt / image` 四个字段，`date / update / author` 会被忽略，要在后台表单里补。

### Q：导入提示「内容过大」

浏览器 `sessionStorage` 有容量上限（约 5MB）。把正文拆成几篇，或直接粘贴进编辑器。

### Q：导入的正文带了一堆 `---`

文件开头的 frontmatter 格式不对（缺结束的 `---`），会被当成正文。检查首尾各有一个 `---`。

---

## 三、Markdown 与排版

### Q：代码块不高亮

没标语言。写成 ` ```javascript ` 而不是光秃秃的 ` ``` `。

### Q：目录里出现了重复的一级标题

正文里写了 `#`。一级标题应该只由「标题」字段提供，正文从 `##` 开始。

### Q：写的内容被吃掉了

- ` ```embed board:xxx ` ——这个语法**已移除**，现在按普通代码块显示
- 手写 HTML 标签可能被过滤
- 标题和段落之间要空一行，否则不会渲染成标题

### Q：表格在手机上挤成一团

列数超过 5 列就会这样。拆成两个表，或改成列表。

---

## 四、图片

### Q：图片不显示

1. 地址对不对（图库图片、外链、上传后的地址三者不同）
2. 外链是否禁止了防盗链
3. 图库里的 `R16 / R18` 分类需要管理员身份才加载

### Q：上传失败

- 单张上限 **10MB**
- 只接受常见图片格式（jpg / png / gif / webp / svg）
- 上传会自动转 WebP，体积会变但不是无损

### Q：封面是随机图

封面留空时，保存会从图库随机挑一张。不想要随机就在保存前手动选。

## 五、AI 相关

### Q：前台 AI 助手不回话

1. 后台「博客设置 → AI 设置」里确认 AI 助手已启用、模型与 API Key 已填
2. 点「测试连接」验证
3. 报「认证失败」= Key 无效或过期；报「请求频繁」= 上游限流
4. 注意 `/api/ai` 是服务端代理，浏览器里看不到 Key 是正常的

### Q：后台写作页的 AI 显示「未配置」

写作 AI 是**独立配置**，不复用前台助手的 Key（未填时才复用）。去「AI 设置 → 写作 AI」单独填一次。

### Q：能让 AI 直接写一篇并发布吗

站内的两个 AI 都**不写正文**：访客助手只聊天，写作助手只回答写作问题、不读正文。
写文章请按 [05-AI-写文章指南](./05-AI-写文章指南.md) 走：外部 AI 产出内容 → 粘进后台 → 手动发布。

### Q：AI 回复里有 Emoji

说明系统提示词被改过。本站在提示词层要求不用 Emoji，可在「AI 设置 → 系统提示词」里补回这条约束。

## 六、后台与权限

### Q：忘了后台密码

优先级：环境变量 `ADMIN_KEY` → Blobs `blog-auth` 的 `password` → 默认 `1111`。
能改环境变量就在部署平台改，改完重新部署即可。

### Q：登录后操作都提示未授权

密钥过期或请求头没带上。退出重新登录一次。

### Q：图库的 R16 / R18 看不到

这类分类需要管理员身份 + 图库密码，非管理员一律不可见，属于设计如此。

---

## 七、阅读体验

### Q：字号 / 行距 / 主题不生效

这些偏好存在浏览器本地。无痕窗口、清了站点数据、换了设备都会重置。

### Q：手机上找不到目录

宽屏 ≤773px 时目录栏隐藏，点右下角悬浮球，菜单里有「目录」。

### Q：长文章打开很慢

超过 30000 字会自动分章，阅读端按需加载。若仍然慢，检查图片体积。

---

## 八、还是不行

1. F12 打开控制台，看 Network 里失败请求的状态码与返回体
2. 带 `x-admin-key` 的接口报 401 → 密钥问题
3. 报 500 → 看 Functions 日志
4. 记录「做了什么 → 期望什么 → 实际什么」，再去看对应模块的代码
