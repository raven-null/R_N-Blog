# 个人博客系统 - 项目文档

## 项目简介

这是一个基于纯前端技术的个人博客系统，专为GitHub Pages设计。支持Markdown文件直接渲染、标签分类、多主题切换、AI智能助手等功能。

## 特性

- ✅ **纯前端实现** - 无需后端服务器，直接部署到GitHub Pages
- ✅ **Markdown支持** - 丢入.md文件即可显示
- ✅ **标签分类** - 自动提取标签，支持分类筛选
- ✅ **十套主题** - 内置10种主题风格，支持扩展
- ✅ **科技感设计** - 现代化UI设计，CSS动画效果
- ✅ **响应式布局** - 适配各种屏幕尺寸，移动端专属悬浮球菜单
- ✅ **代码高亮** - 支持多种编程语言，一键复制代码
- ✅ **图片灯箱** - 点击图片放大查看，支持缩放和拖拽
- ✅ **AI助手** - 内置智能对话助手，支持拖拽和调整大小
- ✅ **文章目录** - 自动生成目录，支持搜索和自动高亮
- ✅ **SEO友好** - 语义化HTML结构

## 技术栈

| 技术 | 用途 | 版本 |
|------|------|------|
| HTML5 | 页面结构 | - |
| CSS3 | 样式和动画 | - |
| JavaScript | 交互逻辑 | ES6+ |
| marked.js | Markdown解析 | 本地加载 |
| highlight.js | 代码高亮 | 11.x（本地加载） |
| 智谱GLM-4 | AI对话 | API调用 |

## 核心模块

### 1. ThemeManager (theme.js)

主题管理系统，负责主题切换和CSS变量管理。

#### 主要功能

- 主题初始化和切换（循环切换10套主题）
- CSS变量动态更新
- 主题持久化（localStorage）
- 创建主题切换按钮

#### 内置主题

| 主题名称 | 标识 | 图标 | 说明 |
|----------|------|------|------|
| Dark | dark | ◐ | 暗黑模式（默认） |
| Light | light | ○ | 白色模式 |
| Cyberpunk | cyberpunk | ◈ | 赛博朋克（紫色霓虹风格） |
| Sepia | sepia | ◎ | 复古纸张（暖色调，适合阅读） |
| Neon | neon | ◆ | 霓虹风格（深紫底色 + 粉青点缀） |
| Nord | nord | ❖ | Nord 配色（冷色调灰蓝，护眼舒适） |
| Dracula | dracula | ❂ | 吸血鬼主题（深紫灰 + 紫色强调） |
| Ocean | ocean | ≋ | 深海风格（深蓝底色 + 青绿强调） |
| Forest | forest | ♧ | 森林风格（深绿底色 + 绿色强调） |
| Sunset | sunset | ☀ | 日落风格（深红底色 + 粉橙强调） |

#### 主题结构

```javascript
{
    name: '主题名',
    icon: '图标',  // 单字符图标
    colors: {
        '--bg-primary': '#背景色',
        '--bg-secondary': '#次要背景',
        '--bg-tertiary': '#三级背景',
        '--bg-card': '#卡片背景',
        '--text-primary': '#主文字',
        '--text-secondary': '#次要文字',
        '--text-muted': '#弱化文字',
        '--accent': '#强调色',
        '--accent-dim': '#次要强调色',
```

#### 扩展接口

```javascript

ThemeManager.nextTheme();

// 设置指定主题

// 获取当前主题配置
const currentTheme = ThemeManager.getCurrentTheme();

// 创建主题切换按钮
ThemeManager.createThemeToggle(container);
```

### 2. MarkdownParser (markdown.js)

Markdown解析器，负责解析frontmatter和渲染Markdown内容。

#### 主要功能

- Frontmatter解析（YAML格式）
- Markdown渲染（使用marked.js）
- 代码高亮（使用highlight.js）
- 摘要提取（自动提取前150个字符）
- 图片提取（提取第一张图片作为封面）
- 高亮扩展（支持 `==文字==` 语法）
- 自定义渲染器（图片、代码块、引用块）

#### Frontmatter格式

```yaml
---
title: 文章标题
date: 2026-07-21
tags: [标签1, 标签2]
author: 作者名
excerpt: 文章摘要
image: images/cover.jpg  # 可选，封面图片路径
---
```

#### 自定义渲染器

**图片渲染器：**
- 自动添加说明文字（alt文本）
- 支持懒加载
- 点击打开灯箱

**代码块渲染器：**
- 自动添加语言标签
- 一键复制按钮
- 代码高亮

**引用块渲染器：**
- 一键复制按钮
- 自定义样式

### 3. BlogApp (app.js)

核心应用逻辑，负责文章加载、渲染和交互。

#### 主要功能

- 文章加载和管理
- 标签筛选
- 搜索功能（按标题、摘要、标签搜索）
- 分页显示
- URL路由管理（支持标签和页码参数）
- 文章卡片渲染（瀑布流布局）
- 统计数据计算（文章数、标签数、总字数）

#### 配置选项

```javascript
config: {
    postsDirectory: 'posts',    // 文章目录
    postsPerPage: 10            // 每页显示数量
}
```

#### 文章数据结构

```javascript
{
    filename: 'article.md',      // 文件名
    title: '文章标题',           // 标题
    date: '2026-07-21',          // 日期
    tags: ['技术', '教程'],      // 标签数组
    author: '作者名',            // 作者
    excerpt: '文章摘要...',      // 摘要
    image: 'images/cover.jpg',   // 封面图片
    content: '正文内容...',      // Markdown内容
    frontmatter: { ... }         // 原始frontmatter
}
```

### 4. AIChat (chat.js)

AI智能对话助手，使用智谱GLM-4-Flash API。

#### 主要功能

- 对话窗口（可拖拽、可调整大小）
- 消息发送和接收
- 打字指示器
- 对话历史保存（localStorage）
- 清空对话
- 系统提示词（管理员人格）

#### 配置选项

```javascript
config: {
    apiUrl: 'https://open.bigmodel.cn/api/paas/v4/chat/completions',
    apiKey: 'YOUR_API_KEY_HERE',  // 智谱API Key
    model: 'glm-4-flash',         // 模型选择
    maxTokens: 1024               // 最大token数
}
```

#### 支持的模型

| 模型 | 说明 |
|------|------|
| glm-4-flash | 快速模型（默认） |
| glm-4 | 标准模型 |
| glm-4v | 多模态模型（支持图片） |

#### 系统提示词

```javascript
{
    role: 'system',
    content: '你是一名博客管理员，名叫渡鸦_001。你的职责是：1. 热情友好地接待每一位访客；2. 回答关于博客内容、技术文章的问题；3. 你的所有回复都要体现你作为管理员的身份。'
}
```

## 页面说明

### 首页 (index.html)

首页包含以下区域：

1. **英雄区域** - 博客标题和描述，粒子动画背景，统计数据（文章数、标签数、总字数）
2. **导航栏** - 标签筛选链接、搜索图标、博客品牌
3. **标签筛选** - 按标签分类显示文章
4. **文章瀑布流** - 卡片式文章展示，支持封面图片
5. **分页** - 文章分页导航
6. **页脚** - 版权信息、链接
7. **主题切换** - 右下角浮动按钮
8. **AI助手** - 右下角聊天图标

### 文章详情页 (article.html)

文章详情页包含：

1. **左侧目录栏** - 固定定位，自动生成文章目录，支持搜索
2. **返回按钮** - 返回上一页或首页
3. **文章头部** - 标题、作者、日期、标签
4. **文章内容** - Markdown渲染后的内容
5. **代码复制** - 代码块和引用块一键复制
6. **图片灯箱** - 点击图片放大查看，支持缩放和拖拽
7. **文章导航** - 上一篇/下一篇
8. **移动端悬浮球** - 目录、返回、首页、主题、AI助手快捷操作

## 功能详解

### 图片灯箱

文章中的图片支持灯箱功能：

- 点击图片打开灯箱放大查看
- 支持鼠标滚轮缩放（0.5x - 5x）
- 支持拖拽已缩放的图片
- 按 `ESC` 或点击外部区域关闭
- 移动端支持触摸缩放

### 代码复制

文章中的代码块和引用块支持一键复制：

- 代码块右上角显示复制按钮
- 引用块右上角显示复制按钮
- 点击后显示"已复制"提示
- 2秒后自动恢复原始状态

### 移动端适配

博客针对移动端进行了专门优化：

- **悬浮球菜单**：屏幕宽度 < 773px 时显示右下角悬浮球
- **弹出菜单**：点击悬浮球显示目录、返回、首页、主题、AI助手等快捷操作
- **侧边栏**：移动端目录栏通过悬浮球菜单打开，覆盖全屏
- **响应式布局**：文章卡片自动适配不同屏幕尺寸

## 性能优化

1. **本地加载** - 第三方库已下载到本地，无CDN依赖
2. **图片懒加载** - 支持图片懒加载
3. **CSS动画** - 使用CSS3动画，性能更好
4. **系统字体** - 使用系统默认字体，无外部字体依赖
5. **本地存储** - 主题和对话历史保存在localStorage

## 安全考虑

1. **XSS防护** - Markdown渲染时进行HTML转义
2. **CSP策略** - 建议配置Content Security Policy
3. **HTTPS** - GitHub Pages默认支持HTTPS
4. **API Key** - 建议在生产环境中使用环境变量管理API Key

## 已知限制

1. **纯前端限制** - 无法实现真正的后端功能
2. **文件数量** - 大量文章可能影响加载速度
3. **搜索功能** - 基础的客户端搜索
4. **评论系统** - 需要第三方服务
5. **AI助手** - 需要有效的API Key
