# 个人博客系统 · 项目文档

## 项目简介

这是一个基于**纯前端技术**的个人博客系统，专为 GitHub Pages 设计，无需后端服务即可运行。文章以 Markdown 文件形式存放在 `posts` 目录，丢入 `.md` 文件并更新清单即可发布。系统集成了四视图（文章 / 图库 / 推荐 / 我的）首页、十套主题、AI 对话助手、图库相册、RSS 订阅等功能，部署于自定义域名 `ravennull.work`。

## 特性

- ✅ **纯前端实现** - HTML5 / CSS3 / 原生 JS（ES6+），无框架、无构建步骤，直接部署 GitHub Pages
- ✅ **Markdown 文章** - `posts` 目录存放 `.md` 文件，frontmatter 提供元数据，支持标签、封面、摘要、更新时间
- ✅ **四视图首页** - 顶栏滑块切换：文章（瀑布流卡片）/ 图库（灯箱相册）/ 推荐（外链精选卡片）/ 我的（个人仪表盘）
- ✅ **标签体系** - 顶部标签面板展示全部标签及文章计数，支持筛选与 URL 路由
- ✅ **十套主题** - Dark / Light / Cyberpunk / Sepia / Neon / Nord / Dracula / Ocean / Forest / Sunset，CSS 变量驱动，自动持久化
- ✅ **AI 助手** - 智谱 GLM-4-Flash 对话，流式输出、多会话管理、划词问答、快捷指令
- ✅ **阅读体验** - 阅读工具栏（字号 / 行距 / 字体 / 护眼 / 夜间 / 专注）、左侧目录（可折叠、可搜索、自动高亮）、进度条、快捷键
- ✅ **代码高亮** - highlight.js 支持多种语言，代码块 / 引用块一键复制
- ✅ **图片灯箱** - 文章图片与图库图片均支持灯箱查看，滚轮缩放、拖拽、上下篇切换、幻灯片放映、下载
- ✅ **Anime.js 动效** - 卡片入场、主题过渡、视图切换、标签面板错峰等，遵循系统"减少动效"设置
- ✅ **响应式** - 大屏 4 列 / 中屏 3 列 / 小屏 2 列 / 移动端 1 列，文章页移动端悬浮球快捷操作
- ✅ **RSS 订阅** - 根目录 `feed.xml` 提供 RSS 2.0 订阅
- ✅ **SEO 友好** - 语义化 HTML 结构，本地加载无 CDN 依赖

## 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| HTML5 / CSS3 | 页面结构与样式 | 语义化标签，CSS 变量驱动主题 |
| JavaScript | 交互逻辑 | 原生 ES6+，模块化对象 |
| marked.js | Markdown 解析 | 本地加载（`js/vendor/marked.min.js`） |
| highlight.js | 代码高亮 | 11.x（本地加载），配合 `css/highlight-github-dark.min.css` |

| 不蒜子 | 访问统计 | 异步引入第三方脚本（`busuanzi.pure.mini.js`） |

## 核心模块详解

### 1. BlogApp（js/app.js）— 首页核心逻辑

负责首页所有功能，页面加载后通过 `BlogApp.init()` 启动。

#### 主要功能

- **文章加载** - 读取 `posts/manifest.json` 获取文件清单，并行 fetch 所有文章，解析 frontmatter；结果按日期降序排序，元数据缓存到 `sessionStorage`（键 `blog-posts-data-v3`，带版本号自动失效）
- **封面选择** - 优先级：`frontmatter.image` → 正文第一张图片 → 按文件名哈希从 `images/BG`（28 张 webp）取固定封面
- **标签筛选** - `filterByTag(tag)` 过滤文章，更新导航激活态与 URL（`?tag=`），支持 `popstate` 路由回退
- **搜索** - `searchPosts(query)` 按标题、摘要、标签即时匹配；搜索框与标签面板互斥，关闭时仅在有关键词时才重置渲染以避免瀑布流位移
- **加载更多** - 每批 `postsPerPage`（10 篇）追加渲染，全部加载后显示"已加载全部 N 篇"
- **文章卡片** - 瀑布流布局，展示封面、NEW 徽标（3 天内）、作者头像、标签、标题、摘要、日期与预计阅读时长（300 字/分钟）
- **视图切换** - `switchView()` 四视图互斥，顶部滑块指示器用 Anime.js 平滑移动；图库 / 推荐 / 仪表盘首次进入时渲染
- **图库渲染** - 读取 `images/R-N-picture/manifest.json`，渲染瀑布流网格；灯箱支持上下篇、幻灯片、下载、页码显示
- **推荐渲染** - 读取 `data/recommendations.json`（内容哈希缓存），按文章/视频/网页/应用类型筛选；视频卡点击在页面内灯箱用 `embed` 链接播放
- **仪表盘渲染** - 统计卡片（文章 / 标签 / 总字数 / 图库图片）、最近 5 篇文章、热门标签 Top 8

#### 配置项

```javascript
config: {
    postsDirectory: 'posts',   // 文章目录
    postsPerPage: 10           // 每页 / 每批加载数量
}
```

#### 文章数据结构

```javascript
{
    filename: '04-animejs-guide.md',  // 文件名
    title: '文章标题',                // 标题
    date: '2026-08-05',              // 发布日期
    tags: ['技术', '教程'],          // 标签数组
    author: '渡鸦NULL',              // 作者
    excerpt: '文章摘要...',          // 摘要（frontmatter 或自动提取前 150 字符）
    image: 'images/BG/01_BG.webp',   // 封面图片
    content: '正文内容...',          // Markdown 正文

}
```

### 2. MarkdownParser（js/markdown.js）— Markdown 解析器

负责 frontmatter 解析与 Markdown 渲染。

#### 主要功能

- **Frontmatter 解析** - `parseFrontmatter()` 支持 `- item` 列表形式与 `[a, b]` 数组形式，返回 `{ frontmatter, content }`
- **Markdown 渲染** - 基于 marked（开启 `gfm`、`breaks`），通过 `marked.use()` 注册 `==文字==` 高亮扩展，输出 `<mark>` 标签
- **自定义渲染器**：
  - **图片** - 输出 `<figure class="img-figure">`，alt 文本作为图注；懒加载 + 加载失败占位图；点击调用 `openLightbox()` 打开灯箱
  - **代码块** - 输出 `.code-block` 容器，带语言标签与复制按钮，交由 highlight.js 高亮
  - **引用块** - 输出 `.quote-block`，右上角带复制按钮
- **辅助方法** - `loadFromFile()`（fetch + 解析）、`extractExcerpt()`（去除 Markdown 标记提取前 150 字符摘要）、`extractFirstImage()`（提取正文第一张图片）、`simpleParse()`（无 marked 时的降级解析）

#### 核心行为

- `init()` 从 `localStorage` 读取 `blog-theme`（默认 `dark`）并应用

- 切换结果写入 `localStorage`，并同步更新页面上所有 `.theme-toggle` 按钮图标

### 4. AIChat（js/chat.js）— AI 对话助手

使用智谱 BigModel GLM-4-Flash API，为文章页提供对话能力。

#### 配置选项

```javascript
config: {
    apiUrl: 'https://open.bigmodel.cn/api/paas/v4/chat/completions',
    apiKey: 'YOUR_API_KEY_HERE',   // 智谱 API Key
    model: 'glm-4-flash',          // 模型选择
    maxTokens: 2048,               // 最大 token 数
    temperature: 0.7               // 采样温度
}
```

#### 主要功能

- **流式输出** - `stream: true` 走 SSE，逐行解析 `data:` 增量；渲染限流（≥50ms 一次，`requestAnimationFrame` 调度）减少重排；支持"停止生成"（`AbortController`）
- **请求健壮性** - `fetchWithRetry` 对 429 / 网络错误指数退避重试；友好的错误提示（限流 / 认证 / 接口 / 服务不可用）
- **多会话管理** - 会话面板支持新建 / 切换 / 删除，以首条用户消息自动命名；存于 `localStorage`（`chat-sessions`、`chat-current-session`）
- **上下文窗口** - 系统提示词 + 最近 10 轮（`MAX_HISTORY_ROUNDS`）历史，滑动窗口裁剪
- **Markdown 渲染** - 助手回复经 `MarkdownParser.parseMarkdown()` 渲染并高亮代码；每条回复带"复制 / 重新生成"快捷操作
- **划词助手** - 选中文章正文文字弹出气泡，一键"解释 / 翻译 / 润色"并发送给 AI
- **快捷指令** - 输入 `/` 唤起菜单：`/解释`、`/翻译`、`/润色`、`/总结`、`/写代码`
- **窗口交互** - 可拖拽、可调整大小（最小 280×300），位置与尺寸记忆（`localStorage`）；未读消息角标、字数统计（上限 2000）、回车发送 / Shift+Enter 换行、防抖重复发送

#### 系统提示词

```javascript
systemPrompt: '你是一名博客管理员，名叫渡鸦_001。你的职责是：1. 热情友好地接待每一位访客；2. 回答关于博客内容、技术文章的问题；3. 你的所有回复都要体现你作为管理员的身份，比如"欢迎来到我的博客"、"感谢阅读我的文章"等。你博学多才，乐于助人。'
```

### 5. BlogAnimations（js/animations.js）— 全局动画控制器

Anime.js v4 的封装层，所有动画统一入口，未加载或系统减少动效时优雅降级。

- **`reducedMotion`** - 检测 `prefers-reduced-motion: reduce`
- **`ready`** - `anime` 已加载且未开启减少动效
- **卡片入场** - `initCardEntrance()`：IntersectionObserver 监听 `.card`，首批完整入场（位移+缩放+淡入），后续渲染（分页/筛选）仅快速淡入，避免"刷新感"；MutationObserver 接管动态渲染的卡片
- **标签面板错峰** - `animateTagsPanel()`：标签按钮从中心向两侧错峰弹出
- **主题过渡** - `transitionTheme(colors)`：为纯色 CSS 变量运行动画，`--shadow`/`--glow` 直接应用
- **文章内容入场** - `animateArticleContent(container)`：正文子元素逐条渐入
- **聊天窗口** - `isChatAnimeEnabled()`：由 chat.js 决定开关动画是否启用

### 6. Reader（js/reader.js）— 文章页阅读增强

自执行模块（IIFE），不污染全局。

- **阅读进度条** - 顶部的 `#articleProgress` 随滚动更新
- **工具栏** - 字号（13-22px，默认 16）、行距（1.6 / 1.8 / 2.0 循环）、衬线/无衬线字体、护眼（sepia）、夜间（dark）模式、专注阅读（聚焦正文淡化其余）
- **模式实现** - 护眼 / 夜间模式通过覆盖 CSS 变量实现，仅清理本模块设置过的变量键，不干扰 theme.js 的主题
- **持久化** - 所有设置存于 `localStorage`（键 `reader-settings`）
- **快捷键** - `j` / `k` 上一篇 / 下一篇，`t` 回顶，`b` 到底，`/` 聚焦目录搜索，`Esc` 退出专注模式
- **目录默认展开** - 页面加载时清除折叠状态，且不记忆折叠状态（保持默认展开）

### 7. 首页页面脚本（index.html 内嵌）

- **滚动 UI** - 阅读进度条、回到顶部按钮（滚动 >400px 显示）、页脚进入视口时隐藏右侧固定按钮，均绑定到 `.scroll-area`
- **快捷键** - `w/s` 上下滚动，`a/d` 前进后退，`q` 切换主题，`Esc` 关闭搜索/图库灯箱，方向键切换图库图片
- **图库灯箱** - 上下篇循环切换、2.5s 幻灯片播放/暂停、下载、页码计数，Anime.js 入场
- **全屏切换** - 点击顶部品牌切换全屏
- **仪表盘时钟** - 欢迎区实时日期时间

## 页面说明

### 首页（index.html）

采用"固定头部内部滚动区"布局，`body` 不滚动，滚动发生在 `.scroll-area`，滚动条仅在下部内容区显示。

1. **顶部栏（top-bar）** - 左侧品牌（点击全屏切换），右侧四视图切换按钮 + Anime.js 滑块指示器
2. **吸顶导航（nav-bar）** - 静态标签链接（全部 / 技术 / 生活 / AI）+ 标签面板按钮（展示全部标签及计数）+ 搜索框
3. **滚动区（scroll-area）** - 内部滚动，承载主内容与页脚
4. **文章视图** - 瀑布流卡片 + "加载更多"按钮
5. **图库视图** - 瀑布流网格 + 灯箱（切换 / 幻灯片 / 下载）
6. **推荐视图** - 筛选胶囊（全部/文章/视频/网页/应用）+ 外链卡片网格；视频卡点击页面内播放（embed 灯箱）
7. **我的视图** - 欢迎区（头像 / 身份 / 实时时钟）、统计卡片、最近文章、热门标签、快捷入口（GitHub / RSS / 写文章）、关于
8. **页脚** - 版权、文章数统计、GitHub / RSS / About 链接
9. **浮动元素** - 阅读进度条、回到顶部按钮、图库灯箱、视频播放灯箱、主题切换按钮、AI 助手（首页仅由 theme.js 生成主题按钮；AI 助手入口在文章页）

### 文章详情页（article.html）

1. **左侧目录栏（toc-sidebar）** - 固定定位；顶部为返回 / 首页 / 主题 / AI 助手操作按钮，下方为目录面板（标题、搜索框、折叠按钮、h1-h6 分层列表）；滚动时高亮当前章节并自动居中
2. **阅读工具栏（reader-toolbar）** - 字号增减、行距、字体、护眼、夜间、专注
3. **文章头部** - 标题、作者、日期、更新时间（如有）、标签
4. **文章正文** - Markdown 渲染，图片灯箱、代码高亮与复制、引用复制
5. **文章导航** - 上一篇 / 下一篇（基于 manifest 排序）
6. **图片灯箱** - 滚轮缩放（0.5x-5x）、拖拽、Esc 关闭
7. **阅读进度条** - 页面顶部
8. **移动端（<773px）** - 目录栏转为抽屉（左侧滑入 + 遮罩），右下角悬浮球弹出菜单（目录 / 返回 / 首页 / 主题 / AI 助手）

## 主题系统

系统使用 CSS 变量驱动主题，所有 UI（导航栏、卡片、滚动条等）均跟随主题变化。

```css
:root {
    --bg-primary: #0a0a0a;      /* 主背景色 */
    --bg-secondary: #111111;    /* 次要背景 */
    --bg-tertiary: #1a1a1a;     /* 三级背景 */
    --bg-card: #0f0f0f;         /* 卡片背景 */
    --text-primary: #f0f0f0;    /* 主文字颜色 */
    --text-secondary: #b0b0b0;  /* 次要文字 */
    --text-muted: #666666;      /* 弱化文字 */
    --accent: #ffffff;          /* 强调色 */
    --accent-dim: #888888;      /* 次要强调色 */
    --border: #222222;          /* 边框色 */
    --border-light: #2a2a2a;    /* 浅边框色 */
    --shadow: rgba(0, 0, 0, 0.5);   /* 阴影色 */
    --glow: rgba(255, 255, 255, 0.05); /* 发光色 */
}
```

主题对象定义于 `theme.js` 的 `themes` 对象，含 `name` / `icon` / `colors` 三个字段；切换时通过 `BlogAnimations.transitionTheme()` 用 Anime.js 平滑过渡纯色变量（`--shadow`/`--glow` 直接应用），并持久化到 `localStorage`。

### 动画效果

- **卡片入场** - 首批完整入场，后续仅快速淡入（IntersectionObserver + Anime.js）
- **主题过渡** - CSS 变量 400ms 平滑过渡
- **视图切换** - 内容淡入 + 滑块指示器移动
- **标签面板错峰** - 标签按钮从中心错峰弹出
- **文章正文入场** - 子元素逐条渐入
- **聊天窗口开关** - 缩放 + 位移 + 淡入

全部遵循 `prefers-reduced-motion`：系统开启"减少动效"时所有 Anime.js 动画直接降级为即时应用。

## 性能与兼容性

### 性能优化

1. **本地加载** - 第三方库（marked / highlight / anime）均已下载到 `js/vendor`，无 CDN 依赖
2. **图片懒加载** - 文章卡片、图库、正文图片均使用 `loading="lazy"`，正文图片附加 `decoding="async"`
3. **动画性能** - 仅使用 `transform` / `opacity` 动画，避免触发重排回流
4. **减少动效** - 全站尊重 `prefers-reduced-motion`
5. **会话缓存** - 文章元数据缓存到 `sessionStorage`（仅缓存元数据与字数，不缓存正文），避免刷新重复请求
6. **流式渲染限流** - AI 回复流式渲染 ≥50ms 节流，减少 DOM 频繁重排
7. **分批高亮** - 代码块按 10 个一批在 `requestAnimationFrame` 中处理，不阻塞首屏
8. **WebP 封面** - 封面 / 头像统一使用 webp 格式

## 安全考虑

1. **API Key 暴露风险** - `js/chat.js` 中 `config.apiKey` 明文存在前端源码中，任何访问者均可从页面源码读取，存在被滥用/盗刷的风险。当前为纯前端架构的固有取舍，建议：
   - 使用代理服务转发请求并在服务端保管 Key
   - 或定期更换 Key，并开启智谱控制台的用量告警
2. **XSS 防护** - 用户输入（AI 回复）经 marked 渲染为 HTML；Markdown 解析输出为白名单式渲染器。注意：正文中的原始 HTML 会被 marked 保留，投稿内容应视为可信
3. **HTTPS** - GitHub Pages 与自定义域名默认支持 HTTPS，`CNAME` 配置后自动提供证书
4. **链接安全** - 外部链接统一使用 `target="_blank" rel="noopener"`
5. **CSP 建议** - 当前未配置 Content Security Policy；如需要可添加 meta 标签，但需放行 `busuanzi.ibruce.info` 等第三方脚本

## 已知限制

1. **纯前端限制** - 无后端，无法实现服务端渲染、鉴权、动态数据
2. **AI Key 明文** - 前端直接携带 API Key（见安全考虑）
3. **客户端搜索** - 搜索仅匹配标题 / 摘要 / 标签，不做全文检索
4. **评论系统** - 未内置，需接入第三方（Gitalk 等）
5. **文章数量** - 文章全部在客户端并行 fetch，大量文章会显著增加请求数与加载耗时
6. **图库索引手工维护** - 新增图片需手动运行 `build-gallery.js` 生成清单
7. **RSS 手工维护** - `feed.xml` 需手动同步文章变更
