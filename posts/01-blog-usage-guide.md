## 一、首页概览

打开博客首页后，从上到下依次是：**顶部栏**、**吸顶导航栏**、**可滚动内容区**。

### 1.1 顶部栏

- **品牌**：点击左上角「渡鸦_NULL BLOG」可进入/退出全屏模式
- **视图切换滑块**：顶部中央为「文章 / 图库 / 每日新闻 / 我的」四个按钮，带滑块指示器，点击即可切换视图

### 1.2 吸顶导航栏

吸顶固定在顶部，仅在「文章」视图显示：

| 元素 | 功能 |
|------|------|
| 全部 / 技术 / 生活 / AI | 点击按标签筛选文章，当前项高亮 |
| 标签面板 | 点击标签图标，展开「全部标签」列表（含每标签文章数），点击筛选 |
| 搜索 | 点击搜索图标，展开搜索框，实时搜索标题、摘要、标签 |

### 1.3 固定头部内部滚动

页面滚动发生在头部下方的 `#scrollArea` 区域内，顶部栏与导航栏始终固定不滚动；右侧还有**阅读进度条**与**回到顶部**按钮。

## 二、文章视图

### 2.1 瀑布流卡片

文章以瀑布流卡片展示，每张卡片包含：

- **封面图**：取 frontmatter 的 `image`；无图时自动取正文首图，或按文章名从 `images/BG/` 生成固定封面
- **作者头像**：按作者名自动匹配 `images/TX/` 下头像（见下表），作者名取 frontmatter 的 `author`
- **作者名 / 标签 / 标题 / 摘要**
- **日期与阅读时长**：底部显示发布日期和预计阅读时间（按每 300 字约 1 分钟估算）
- **懒加载**：封面图片使用 `loading="lazy"`，滚动到可视区域才加载

**头像匹配规则：**

| 作者 | 头像 |
|------|------|
| 渡鸦NULL | `images/TX/01_TX.webp` |
| AI | `images/TX/02_TX.webp` |
| 其他 | `images/TX/03_TX.webp` |

### 2.2 全部加载

首页一次性加载并展示全部文章（无分页、无需点击「加载更多」）。资讯已独立到「每日新闻」视图，见第四章。

## 三、图库视图

### 3.1 图库数据来源

图库图片统一存放在 `images/R-N-picture/` 文件夹。添加图片后运行脚本即可生成图片清单：

```bash
node scripts/build-gallery.js
```

脚本会扫描该目录下的图片（jpg/jpeg/png/webp/gif/svg/bmp），生成 `images/R-N-picture/manifest.json`，图库页面据此渲染。

### 3.2 灯箱查看

点击任一张图片弹出全屏灯箱，支持：

- **左右切换**：点击左右按钮，或键盘 `←` / `→`
- **页码显示**：右上角显示「当前 / 总数」
- **幻灯片播放**：点击「播放」自动轮播，可随时暂停
- **下载**：一键下载当前图片
- **关闭**：点击背景、关闭按钮或按 `ESC`

## 四、每日新闻视图

「每日新闻」视图位于「图库」与「我的」之间，以**列表形式**集中展示聚合资讯（无卡片图片），支持按**新闻出品方**筛选。

### 4.1 新闻列表

- 每行一条：**出品方徽标 + 标题 + 出品方 · 日期**，悬停有高亮与左移效果
- 顶部筛选栏：**全部 / 各出品方**（IT之家 / 36氪 / GitHub Blog 等），点击即时过滤
- 点击新闻条目：新窗口打开原文链接；有站内正文的进入文章页站内阅读

### 4.2 数据来源

资讯数据优先来自后端 NewsNow API（`/api/news`），失败时回退本地 `data/recommendations.json`，每条记录包含：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | ✅ | 唯一标识（如 `n01`） |
| `title` | ✅ | 新闻标题 |
| `url` | ✅ | 原文链接（http/https） |
| `source` | ✅ | 来源网站 / 媒体名称 |
| `category` | 推荐 | 资讯分类（如 科技 / 开发 / AI） |
| `date` | 推荐 | 发布日期，格式 YYYY-MM-DD |
| `summary` | 可选 | 一句话摘要 |

### 4.3 更新方式

- **自动（推荐）**：GitHub Actions 每天 08:00 抓取各来源 RSS（36氪 / 量子位 / 少数派 / 虎嗅 / 阮一峰 / CSS-Tricks / GitHub Blog）自动生成并提交，无需手动操作
- **手动**：编辑 `data/recommendations.json` 后提交推送即可；本地预览 `node scripts/update-news.js --dry`
- 校验：`node scripts/check-recommendations.js`（`--check` 附加链接体检）

## 五、我的视图（仪表盘）

「我的」视图展示个人仪表盘，从上到下包含：

- **欢迎区 + 时钟**：头像、昵称、简介，右侧实时日期与时间（每秒更新）
- **统计**：文章数 / 标签数 / 总字数 / 图库图片数
- **留言区**：填写昵称与留言即可发表（邮箱可选），数据存于后端 Netlify Blobs（见第六章）
- **关于**：版本号、技术栈（纯前端 · GitHub Pages）、最后更新日期

## 六、文章页阅读

点击文章卡片进入阅读页。

### 6.1 左侧目录

- **默认展开**：所有子目录默认展开，也可点击右上角按钮一键全部折叠/展开
- **目录搜索**：目录顶部搜索框可快速筛选标题（快捷键 `/` 聚焦）
- **智能折叠**：仅含有子标题的目录项显示折叠图标
- **自动高亮**：滚动时当前章节自动高亮，点击目录项平滑跳转
- 侧边栏还提供「返回」「返回首页」「切换主题」「AI 助手」快捷按钮

### 6.2 阅读工具栏

| 工具 | 功能 |
|------|------|
| A− / A+ | 减小 / 增大字号（13px ~ 22px） |
| 行距 | 在 1.6 / 1.8 / 2.0 之间循环切换 |
| 衬线 | 切换衬线 / 无衬线字体 |
| 护眼 | 复古纸张配色（Sepia 模式） |
| 夜间 | 夜间阅读模式 |
| 专注 | 专注模式，隐藏干扰元素，按 `ESC` 退出 |

阅读设置自动保存，下次打开文章自动恢复。

### 6.3 阅读进度条

页面顶部细进度条，随滚动实时显示阅读进度。

### 6.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| `J` | 跳到下一篇 |
| `K` | 跳到上一篇 |
| `T` | 回到顶部 |
| `B` | 滚到底部 |
| `/` | 聚焦目录搜索框 |
| `ESC` | 退出专注模式 / 关闭灯箱 |

> 另有全局快捷键：`W/S` 上下滚动、`A/D` 浏览器后退/前进、`Q` 切换主题、`E` 开关 AI 助手。

### 6.5 其他阅读功能

- **代码高亮与复制**：代码块自动语法高亮，右上角一键复制（会显示「已复制」反馈）
- **引用复制**：引用块右上角可一键复制内容
- **图片灯箱**：正文图片点击放大，滚轮缩放（0.5x ~ 5x），放大后可拖动
- **文字高亮**：支持 `==文字==` 语法，渲染为黄色高亮
- **上一篇 / 下一篇**：文章底部卡片导航，方便连续阅读
- **留言区**：文章底部（下一篇导航下方）提供留言，填写昵称 + 内容即可发表，数据存于后端，见第六章

## 七、留言系统

文章页与「我的」仪表盘均内置留言功能：

- **入口**：文章底部（下一篇导航下方）与「我的」视图（统计下方）
- **表单**：昵称（必填）、留言内容（必填）、邮箱（可选，不会被公开）
- **存储**：数据通过后端 `/api/comments` 存于 **Netlify Blobs**，按 `postId` 隔离（文章用文件名，仪表盘用 `dashboard`）
- **限制**：单篇最多 500 条；内容最多 5000 字；超过 3 个链接会被拦截（防垃圾）
- 后端不可用时显示「留言功能暂时不可用」

## 八、AI 助手

内置 AI 对话助手（智谱 GLM-4-Flash），入口为右下角浮动按钮或文章页侧边栏按钮。

- **流式对话**：AI 回复逐字流式输出，Markdown 与代码实时渲染
- **停止生成**：回复过程中发送按钮变为「停止」，点击即可中断
- **复制 / 重新生成**：每条 AI 回复下方提供两个操作按钮
- **多会话**：可新建、切换、删除多个会话，历史自动保存在本地
- **划词助手**：在文章正文选中文字，弹出「解释 / 翻译 / 润色」气泡，一键调用 AI 处理
- **快捷指令**：输入框以 `/` 开头唤起指令菜单，支持 `/解释`、`/翻译`、`/润色`、`/总结`、`/写代码`
- **字数统计**：输入框右侧实时显示 `字数/2000`
- **窗口拖拽与位置记忆**：按住标题栏拖动窗口、拖右下角调整大小，位置和大小自动记忆
- **未读角标**：窗口关闭时收到 AI 回复，按钮显示未读数字角标

## 十、发布文章流程

### 10.1 新建文章

在 `posts/` 文件夹创建 `.md` 文件，格式如下：

```markdown
---
title: 文章标题
date: 2026-08-05
update: 2026-08-06
tags:
  - 技术
author: 渡鸦NULL
excerpt: 文章摘要，显示在首页卡片上
image: images/xxx.webp
---

正文内容写在这里...
```

**frontmatter 字段说明：**

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| title | 推荐 | 文章标题，不填则使用文件名 |
| date | 推荐 | 发布日期，格式 YYYY-MM-DD，决定排序 |
| update | 可选 | 最后更新日期，文章页会显示「更新于 xxx」 |
| tags | 可选 | 标签数组（支持 `[技术, AI]` 或列表两种写法），用于筛选 |
| author | 可选 | 作者名，决定卡片头像，不填显示 Anonymous |
| excerpt | 可选 | 摘要，不填自动提取正文前 150 字 |
| image | 可选 | 封面图片路径，不填自动取正文首图或随机封面 |

### 10.2 更新 manifest.json

创建文章后，把文件名加入 `posts/manifest.json` 数组：

```json
[
    "01-blog-usage-guide.md",
    "02-your-new-article.md"
]
```

### 10.3 提交发布

```bash
git add .
git commit -m "发布新文章"
git push origin main
```

> 首页文章数据有 session 缓存（带版本号，旧缓存自动失效），更新代码后如未生效请强制刷新页面（Ctrl+F5）。

## 十一、Markdown 文档编写规则

博客正文使用标准 Markdown 编写，由 marked 库解析渲染（开启 GFM 与 `breaks`）。以下为支持的语法与编写规范，遵循这些规则可保证排版一致、功能生效。

### 11.1 标题

- 使用 `#` 至 `######` 表示一至六级标题，`#` 后需加一个空格
- 一级标题建议只用于文章主标题，正文从二级标题（`##`）开始分层
- 标题会自动生成左侧目录，请保持层级连续、用词精炼

```markdown
## 二级标题
### 三级标题
#### 四级标题
```

### 11.2 文本样式

| 样式 | 语法 | 效果 |
|------|------|------|
| 加粗 | `**文字**` | **文字** |
| 斜体 | `*文字*` | *文字* |
| 加粗斜体 | `***文字***` | ***文字*** |
| 删除线 | `~~文字~~` | ~~文字~~ |
| 行内代码 | `` `代码` `` | `代码` |
| 文字高亮 | `==文字==` | 黄色高亮（自定义扩展） |

### 11.3 列表

无序列表使用 `- ` 开头，有序列表使用 `1. ` 开头；子级在上一级前缩进 2 个空格。

```markdown
- 无序项
  - 子项
- 另一项

1. 第一步
2. 第二步
```

支持 GFM 任务列表：

```markdown
- [x] 已完成
- [ ] 待办
```

### 11.4 链接与图片

**链接**

```markdown
[链接文字](https://example.com)
```

**图片**：语法为 `![描述文字](路径)`，描述文字会渲染为图片下方说明文字（figcaption），点击图片可放大查看：

```markdown
![这是一段图片说明](images/example.webp)
```

> 建议：
> - 图片统一放入 `images/` 下子目录，正文使用相对路径
> - 尽量填写描述文字，无文字则不显示图注
> - 格式支持 jpg / jpeg / png / webp / gif / svg / bmp

### 11.5 代码块

使用三个反引号包裹，并在开头注明语言名以启用语法高亮，右上角自动带复制按钮：

````markdown
```javascript
console.log("Hello");
```
````

| 常用语言名 | 开头写法 |
|------|------|
| JavaScript | ` ```javascript ` |
| HTML | ` ```html ` |
| CSS | ` ```css ` |
| Python | ` ```python ` |
| Bash | ` ```bash ` |
| JSON | ` ```json ` |

> 未指定语言名（` ``` `）时不会高亮，建议始终标注语言。

### 11.6 引用

使用 `>` 开头，支持多级嵌套，引用块右上角可一键复制：

```markdown
> 这是一段引用内容
>
> > 嵌套引用
```

### 11.7 表格

GFM 表格：表头下一行用 `---` 分隔，`:---:` 居中对齐、`:---` 左对齐、`---:` 右对齐：

```markdown
| 名称 | 数量 | 备注 |
|------|:---:|------|
| 苹果 | 10 | 左对齐 |
| 香蕉 | 20 | 右对齐 |
```

### 11.8 分隔线

使用 `---` 单独成行插入分隔线（注意与表格分隔符区分，前后需空行）。

### 11.9 换行与段落

- 开启 `breaks` 后，单个换行也会渲染为换行，无需在行尾加两个空格
- 段落之间用一个空行分隔；连续段落不空行会合并为同一段

### 11.10 特殊字符转义

需要显示 `#` `*` `_` `` ` `` `[` `]` `(` `)` `>` `|` 等语法符号时，用反斜杠转义：

```markdown
\# 不是标题，\*\*不是加粗\*\*
```

### 11.11 编写规范

1. 正文前必须带 `---` frontmatter（见 10.1），中文内容使用全角标点
2. 标题层级不要跳级（如 `##` 后直接用 `####`），保持目录清晰
3. 代码块务必标注语言名；正文里的单行命令用行内代码 `` ` `` 包裹
4. 图片建议配说明文字并放在合适位置，避免与图库图片混用
5. 写完检查一遍：是否有误用的全角冒号 `：`、未闭合的反引号、被忽略的语法符号
6. 特殊符号（如 `==`）误显示时可转义或用行内代码包裹

## 十三、常见问题

### Q: 新文章不显示？

检查以下几点：
1. 文件是否在 `posts/` 文件夹且扩展名为 `.md`
2. frontmatter 格式是否正确（注意用英文冒号 `:`）
3. 文件名是否已加入 `posts/manifest.json`（区分大小写、需含 `.md`）
4. 是否已推送成功；若本地缓存较旧，强制刷新（Ctrl+F5）后重试

### Q: 图库新增图片后不更新？

1. 确认图片已放入 `images/R-N-picture/`（支持 jpg/jpeg/png/webp/gif/svg/bmp）
2. 运行 `node scripts/build-gallery.js` 生成 manifest.json
3. 提交并推送后强制刷新页面

### Q: 样式不生效？

多为浏览器缓存所致，尝试强制刷新（`Ctrl+F5`）或清除缓存后重新访问；仍有问题则检查浏览器控制台（F12）是否有报错。

### Q: AI 助手无法使用？

1. 检查 `js/chat.js` 中的 `apiKey` 是否正确配置
2. API Key 是否过期或额度耗尽
3. 网络是否正常，控制台是否有报错（401/403 为认证失败，429 为限流，请稍后重试）

### Q: 代码没有高亮？

1. 代码块需指定语言名，例如：

````markdown
```javascript
console.log("Hello");
```
````

2. 确认 `js/vendor/highlight.min.js` 与高亮样式文件存在
